# DayProgress

The 14 days as a row of thin bars under an "Day 3 of 14" eyebrow. Finished days `ultraviolet` fills, today a taller `amber` fill, upcoming days `ink-faint` outlines.

- Bars 12pt tall (today 20pt, so it never relies on color alone), `radius-bar`, `space-1` gaps. Setup flows use the same bar style for step progress (5 steps, done steps `amber`).
