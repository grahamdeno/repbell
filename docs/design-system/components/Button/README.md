# Button

Two kinds. **Primary**: `accent` fill, `on-accent` text, at most one per screen, for the thing the screen is for. **Secondary**: transparent, `line-strong` border, `ink` text.

- 60pt tall at the bottom of flow screens; 56pt for secondary actions on Today.
- Corner `radius-button`. Full width unless paired in a two-column row with `space-3` gap.
- Verb or plain word: "Start", "Next", "Done", "Busy for 1 hour".
