# Counter

Slide-to-set count for max tests. The panel fills the free height; a vertical drag sets the number (up adds, down subtracts), with a light haptic tick per rep. The numbers above and below stay visible, and a tick ruler on the right moves with the count. −1 and +1 buttons sit beside Done.

- Starts at 0 on Day 1 and at the previous max on Days 8 and 15.
- About 14pt of drag per rep; tune by feel on device.
- Accessible as an adjustable element: VoiceOver swipe up and down changes the value by one.
- Panel: `surface`, `line` border, `radius-panel`; number in `number-hero` and `accent`.
