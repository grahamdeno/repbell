# SetTally

Today's sets as a grid of marks, so a glance tells done, missed, now and to come. Above it, a `label` row: "Today's sets" and "4 of 21 done, 1 missed".

- Done: `ink` fill. Current: `accent` fill. Upcoming: `line-strong` outline. Missed: dashed `ink-faint` outline.
- Marks are 22pt tall, `radius-set`, in an 11-column grid with 6pt gaps (wraps for days with more sets).
- Never red, never a streak.
